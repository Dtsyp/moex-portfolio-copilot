# Baseline: MOEX Portfolio Copilot

Контекст ДЗ-2. Источник текущего дизайна — [ML System Design Doc](ml_system_design_doc.md); измерения — [EDA](../reports/eda/README.md), `reports/eda/summary.json` и manifest источников. Статус нельзя переносить из планов в реализованные функции без проверки кода.

## Проверенная исходная точка

- ДЗ-2 основано на `hw_1`, commit `5f7d88527f46d58832363ba9de03d0beb68f4602`; ДЗ-1 ещё в отдельном PR.
- В исходной `hw_1` были README, дизайн-документ, Ruff/pre-commit и пустые каталоги кода, тестов и ноутбуков.
- ДЗ-2 охватывает сбор реальных источников, описательный EDA и проектирование следующих этапов. Обучение, полный бэктест, оптимизатор, MLflow, API и интерфейс не заявляются выполненными.
- Назначение проекта: образовательная поддержка портфельных решений, без реальной торговли и интеграции с брокером.

- Измеренный новостной срез: 91 955 исходных записей, 91 477 в development; около 81% без времени публикации, 1 711 повторных нормализованных текстов. У `bcs_tech` 4 417 статей датированы одним днём — требуется проверка timestamp.
- Исследовательский состав: 40 квартальных срезов IMOEX, 1 803 строки и 89 тикеров; это не ежедневная PIT-база индекса. Получено 166 782 свечи; TCSG/T перекрываются на 1 248 датах с отношением цен 10, поэтому коды нельзя считать независимыми инструментами.

## Принятые решения

- Рынок — ликвидные акции/расписки MOEX, long-only; целевой универсум — до 40 бумаг из исторической базы IMOEX по прошлому обороту.
- Горизонты — 5 и 20 общих торговых сессий; отдельные модели, еженедельная/ежемесячная ребалансировка.
- Development-данные — 2015–2024, внешний walk-forward — 2019–2024. Holdout 01.2025–10.2026 закрыт для EDA и подбора правил.
- Квартальные срезы IMOEX определяют только исследовательский список; точный PIT membership ещё требуется.
- Дневные свечи ISS — OHLCV как возвращены источником, включая ретроспективное масштабирование; `close` не равен автоматически закрытию основной сессии. `/history` проверяется отдельно.
- Ценовые метки EDA не являются полной доходностью. Для финального таргета нужны подтверждённые корпоративные события и правила дивидендов.
- Бейзлайны: равные веса, momentum 12–1, HRP без сигнала; модельные кандидаты — Ridge и LightGBM. Новостная ветка допускается отдельной абляцией.
- Оценка — вложенные временные разбиения, purge по фактическому концу/доступности метки, train-only preprocessing. Downsampling раз в 5 дней не устраняет перекрытие h=20.
- Новости — RussianFinancialNews revision `f83da5c05c82c9086806cf90ded4155052f9605c`; исходные train/test не считаются временной финансовой валидацией.
- Сырые ответы и полные тексты локальны; в GitHub публикуются код, агрегаты, графики и manifest. Пользовательские позиции в публичных примерах только синтетические.
- В портфельной оценке сохраняются переоценки удерживаемых позиций через остановки торгов; исключение интервала из модельной метки не удаляет убыток из бэктеста.

## Непроверенные допущения и открытые вопросы

1. Доступны ли полные интервалы исторического состава индекса, включая даты объявления и все выбывшие инструменты?
2. Как восстановить сплиты, обмены/редомициляцию, ex-date, права на дивиденды и денежные поступления без механической склейки тикеров?
3. Когда нужные дневные поля ISS окончательно доступны и как моделировать исторические исправления?
4. Каковы часовой пояс и происхождение времени RFN; есть ли подтверждённая sentiment-разметка и даты корпуса?
5. Какие будущие для бэктеста тексты могли входить в предобучение encoder; где строгая PIT-оценка вообще допустима?
6. Насколько точен entity linking и переносимость RFN→RSS; на каком общем периоде возможна честная абляция?
7. Достаточны ли совместная история для риска и число независимых временных групп для заявленных IC-порогов?
8. Как соблюсти лимиты после лотов/издержек при коротких историях, приостановках и нехватке допустимых инструментов?

Ответы уточняются по фактическим результатам каждого задания. Отсутствие преимущества модели означает неподтверждённый эффект выбранной конфигурации, а не доказанное отсутствие любого сигнала.
