# Design Doc: MOEX Portfolio Copilot

> Черновик. Заполняется по ходу проекта.

## 1. Постановка задачи

Система поддержки портфельных решений для ограниченного универсума акций MOEX: ежедневный сбор данных, признаки, ранжирующие сигналы на горизонтах 1 неделя и 1 месяц, целевой портфель с ограничениями риска и оборота, объяснение решения и мониторинг. Успех определяется воспроизводимостью, отсутствием утечек и корректной оценкой относительно бенчмарков.
